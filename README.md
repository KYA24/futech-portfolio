# FuTech Portfolio — Preview
Arabic-first responsive portfolio prototype for FuTech, a Saudi technology community in development.

**Status:** experimental review site, not an official launch.

## Run locally

```sh
python3 -m http.server 5190
```

No build step, runtime dependencies, database or data collection. HTML/CSS/JavaScript source is directly served by GitHub Pages.

## Content boundaries
- Future experience formats are not advertised as currently available services.
- Historical activity is explicitly attributed to the previous university club phase.
- No legal registration, formal partnership, verified metrics or open registration is claimed.
- Participation buttons open an explanatory preview dialog; no personal data is submitted.
- Images were supplied by the project owner as visual identity references. The standalone SVG mark is a prototype interpretation, not an approved master logo.
- The vision text is reproduced as supplied and approved by the owner. Supporting headlines are editorial proposals.

## Features
RTL responsive layout, keyboard-accessible experience tabs, accessible native dialog, mobile navigation, reduced-motion support, prototype noindex metadata.

## Assets
Five owner-supplied JPG references in `assets/`, preserved without raster editing. Google Fonts loads IBM Plex Sans Arabic with local system fallbacks.
